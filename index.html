Proyecto académico · Análisis y Diseño

Una mejor organización para el cuidado dental.

Dentalia es una propuesta de sistema para apoyar la gestión de pacientes, citas e información clínica de un consultorio dental, facilitando el acceso ordenado a los datos según el rol de cada usuario.

Conocer el proyecto
✦
01 · Presentación

Sobre el proyecto

Control de Gestión e Historial Clínico para un Consultorio Dental.

⌕

¿Qué busca Dentalia?

Organizar la información del consultorio, apoyar el registro y seguimiento de citas y mantener disponible el historial clínico para el personal autorizado.

◎

Objetivo general

Analizar y diseñar un sistema de gestión e historial clínico que contribuya al control de pacientes, citas y atenciones odontológicas.

03 · Acceso al sistema

Roles y responsabilidades

El acceso a la información se organiza según las funciones de cada participante.

☺

Paciente

Solicita o consulta sus citas y revisa la información propia que el sistema permita mostrar.

✚

Odontólogo

Consulta la agenda y la información clínica autorizada; registra consultas, diagnósticos y tratamientos.

▤

Recepcionista

Registra pacientes, gestiona citas, pagos y comprobantes, y consulta reportes administrativos.

Documentación del proyecto

La documentación debe incluir las generalidades, el marco teórico, la planificación, el análisis estructurado y el análisis orientado a objetos.

  • Objetivos, justificación, alcance y metodología.
